# Inventory Management System (Console-based)

This is a simple console-based **Inventory Management System** written in **Java**. It allows users to manage products in an inventory by performing operations like adding, updating, deleting, and viewing products. The program is designed to work in the command line using **core Java** (no GUI).

## Features

- **Add Product**: Allows the user to add a new product with details such as ID, name, quantity, and price.
- **View Products**: Displays all the products currently in the inventory.
- **Update Product Quantity**: Allows updating the quantity of a product.
- **Delete Product**: Allows the user to delete a product from the inventory by its ID.
- **Exit**: Exits the program.

## Requirements

- **Java** (JDK 8 or above)
- **Operating System**: Windows, macOS, or Linux
